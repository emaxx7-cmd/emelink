# Виджет Emeli на iPhone

iOS не разрешает PWA-приложениям напрямую рисовать виджеты на главном экране. Решение — приложение **Scriptable** (бесплатное, App Store), которое умеет рендерить виджеты по JS-скрипту. Виджет показывает прогресс на сегодня, серии и процент.

## Установка (5 минут)

1. **Установи Scriptable** из App Store.

2. **Добавь скрипт.** Открой Scriptable → `+` (новый скрипт) → вставь содержимое файла `emeli-widget.js` → дай имя `Emeli` → сохрани.

3. **Экспортируй данные.** Открой Emeli в Safari → кнопка ⚙ в правом верхнем углу → **«Экспорт для виджета iPhone»**.
   - На iOS 16+ откроется системное окно «Поделиться» → выбери **«Сохранить в Файлы»** → **iCloud Drive → Scriptable**.
   - Имя файла должно остаться `emeli-widget.json`.

4. **Добавь виджет на экран.** Удержи палец на пустом месте главного экрана → `+` сверху → найди **Scriptable** → выбери средний размер → добавь.

5. **Привяжи скрипт.** Удержи новый виджет → «Изменить виджет» → в поле `Script` выбери `Emeli`. В `When Interacting` оставь `Run Script` или поставь `Open URL` чтобы тап открывал PWA.

## Обновление данных

Виджет читает локальный JSON-файл из iCloud Drive — он **не** обновляется автоматически. После того как ты отметил привычки в Emeli:

- Открой Emeli → ⚙ → «Экспорт для виджета» → «Сохранить в Файлы» → перезапиши тот же файл.
- Виджет обновится сам в течение нескольких минут (или удержи виджет → «Обновить»).

Это компромисс: PWA в Safari не имеет постоянного фонового доступа к файловой системе. Если хочется авто-обновления — нужен бэкенд или нативное приложение.

## Кастомизация

В файле `emeli-widget.js` сверху можно поменять:

- `APP_URL` — куда ведёт тап по виджету (по умолчанию опубликованная PWA).
- `FILE` — имя JSON-файла, если переименуешь.
- Цвета фона/акцентов — поищи `new Color('#…')` в коде.

## Не работает

- **Виджет пустой / «Открой настройки»** — JSON-файл не найден. Проверь, что он лежит в `iCloud Drive → Scriptable` и называется ровно `emeli-widget.json`.
- **«Cannot find module»** — Scriptable не дочитал из iCloud. Открой Scriptable, дождись синхронизации, повтори.
- **Кнопка экспорта ничего не делает** — Safari заблокировал share. Попробуй ещё раз с активной вкладкой Emeli.
